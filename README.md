# Currency Converter – Конвертер валют

**Автор:** Шамиль Сарбашев

## Описание
Приложение с графическим интерфейсом (Tkinter) для конвертации валют по актуальным курсам с использованием бесплатного API [exchangerate-api.com](https://www.exchangerate-api.com).  
Возможности:
- Выбор валюты «из» и «в» из 13 популярных валют
- Ввод суммы (обязательное поле, только положительные числа)
- Конвертация по текущему курсу
- Отображение результата и использованного курса
- Таблица истории всех конвертаций с датой/временем, суммами и курсом
- Сохранение истории в JSON-файл (`history.json`) с автоматической загрузкой при запуске
- Кнопка «Очистить историю» с подтверждением

## Как получить API-ключ
**API-ключ не требуется** для использования данного API в бесплатном режиме.  
Однако если вы хотите использовать свой ключ (например, для увеличения лимита запросов):
1. Зарегистрируйтесь на [exchangerate-api.com/sign-up](https://www.exchangerate-api.com/sign-up)
2. Бесплатный план даёт 1500 запросов в месяц без ключа; с ключом – те же 1500, но с возможностью отслеживания.
3. Чтобы добавить ключ, измените код:
